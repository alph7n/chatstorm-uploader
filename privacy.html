Privacy Policy

Look Again Shorts Publisher · Effective 15 November 2026

Look Again Shorts Publisher ("the tool") is a private upload tool for the Chat Storm YouTube channel. It is operated by the channel owner and used only with the owner's own YouTube account. It is not offered to the public.

Data the tool accesses

With the account owner's permission, the tool uses the YouTube Data API to:

  • upload videos, titles, descriptions, tags and thumbnails to the owner's channel;
  • read the channel's name and identifier;
  • read the view, like and comment counts of the channel's own videos.

The tool does not access any other Google account data, and it does not access data of any other person.

How the data is used

The data is used only to publish the channel's videos and to show the owner how those videos perform. It is not used for advertising, profiling or any other purpose.

Storage and sharing

  • The authorization tokens issued by Google are stored only on the owner's own computer.
  • No data received from Google APIs is sold, shared with or transferred to third parties.
  • The tool has no analytics, no tracking and no user accounts.

Google and YouTube terms

The tool uses YouTube API Services. By using it, the account owner agrees to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time on the Google Account permissions page. After access is removed the tool can no longer upload or read anything, and the locally stored tokens stop working.

Contact

Questions about this policy: open an issue on GitHub.
